# Commonroom

Commonroom helps high school students find study partners and recognize classmates who help others learn.

- [`app/`](app/) is a working Python and SQLite MVP with accounts, shared study sessions, and Help Tokens. See its README for how to run it.
- [`demo/`](demo/) is the original browser-only design prototype.
- [`admin/`](admin/) is a visual admin dashboard prototype with fictional data.

The working MVP awards 1 Help Token to each participant when a host completes a session with at least two students. Afterward, a participant may thank one helper, awarding that student 3 more tokens. The app does not yet provide calls or chat; students arrange their conversation separately.
